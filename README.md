# Weather Dashboard 🌤️

A clean, minimal weather dashboard built with HTML, CSS, and JavaScript.

## Features

- Search weather by city name
- Displays temperature, humidity, wind speed, feels like, and visibility
- Error handling for invalid city names
- Press Enter or click Search to query
- Responsive glowing card UI

## Tech Stack

- HTML
- CSS
- JavaScript
- OpenWeatherMap API

## How to Run

1. Clone the repo
2. Add your OpenWeatherMap API key in `script.js`
3. Open `weather-dashboard.html` in your browser
